# Skjermbilder og testbevis

## Reelle appskjermbilder

| Område | Motor og format | Bevis |
|---|---|---|
| Hjem, Norsk, Matte, Engelsk, Geografi | WebKit + Chromium, iPad stående/liggende | [Exact-head iPad-artifakt](https://github.com/Almenning/Flyt-app/actions/runs/45005336898) |
| Engelsk: Words, Reading og Kinnaklova | WebKit + Chromium, iPad stående/liggende | [Engelsk-artifakt](https://github.com/Almenning/Flyt-app/actions/runs/45005337018) |
| Matte: Tallvika oppgaver | WebKit + Chromium, 820×1180, 1024×1366, 1180×820, 1024×768 og 1366×1024 | [Matte-artifakt](https://github.com/Almenning/Flyt-app/actions/runs/45005336945) |
| Brøklab og Gangetabellen | WebKit + Chromium, iPad | [PR #268 testoversikt](https://github.com/Almenning/Flyt-app/pull/268) |

## Begrensning

Disse er faktiske appkjøringer i Playwrights WebKit og Chromium med iPad-viewporter. De dokumenterer ikke fysisk Safari på iPad. Fysisk enhet er en nødvendig fase-5 port.
